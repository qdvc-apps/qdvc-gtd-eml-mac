# QDVC GTD EML for macOS

A native SwiftUI app for macOS 14 (Sonoma) and later that opens a
[qdvc-gtd-eml](https://github.com/qdvc-apps/qdvc-gtd-eml) workspace, shows it
in a Mail-style three-pane window, and performs the core workflow actions of
the command-line tool (ingest, file, close, pin, annotate, autofix) directly
on the workspace.

## Status

Design phase. The proposed design, and the questions still open, are in
[docs/DESIGN.md](docs/DESIGN.md). No code has been written yet.
